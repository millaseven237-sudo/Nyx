Installation en 4 étapes

Compatible panel Katabump (type Pterodactyl).

  1. Télécharge et dézippe
    Mets les fichiers à la racine du serveur, sans node_modules.
  2. Configure
    Ouvre config.js et renseigne OWNER_NUMBER (format international, sans +).
  3. Démarre
    Commande de démarrage : npm start (Node ≥ 20).
  4. Connecte
    WhatsApp → Appareils connectés → Lier avec un numéro, puis saisis le code affiché.

Questions fréquentes

Quelle version de Node.js faut-il ?

Node.js 20 ou supérieur.

La session est-elle conservée ?

Oui, elle est enregistrée dans le dossier session/. Le code de connexion n’est demandé qu’une fois.

Comment vérifier que tout fonctionne ?

Lance npm run check pour tester toutes les commandes sans te connecter.

Le téléchargement ne démarre pas ?

Ouvre cette page dans l’application ou le site claude.ai, puis accepte la confirmation de sauvegarde.
